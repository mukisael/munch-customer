# Munch Customer Web UI v2

Separate files: index.html, style.css, script.js.

Added without changing the food catalogue/design direction: Mobile Money payment number, local account creation/login persistence, Settings (theme/animations/reset), browser geolocation, and device/browser back handling.

Important: this is a front-end prototype. Account credentials are stored locally in the browser for demo purposes; use a secure backend before production. Mobile Money payment is currently an instruction/confirmation flow, not automatic payment verification.
